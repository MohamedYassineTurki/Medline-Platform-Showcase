## How claims were selected

The public descriptions follow the current implementation, not only older planning documents. For example, the current source includes tutor workflows, an integrated forum, richer replay collections, and reporting features that earlier project notes described more narrowly.

Technical package versions were checked privately to identify the stack. Exact operational configuration, source history, implementation-level access rules, internal service topology, and credential material are not included in this showcase.

This is a portfolio presentation, not a security audit or regulatory-compliance report. It makes no certification, benchmark, uptime, revenue, or adoption claim beyond the evidence described here.
